# Исправления личного кабинета и связанных данных

## Выполнено

1. Личный кабинет получил стабильную роль-зависимую область `journal-workspace`. Широкие таблицы больше не растягивают CSS Grid для администратора, преподавателя или ученика после назначения группы произведений.
2. `responsive_tables.js` больше не обращается к удалённому родителю таблицы. Добавлены проверки `isConnected`, очередь через `requestAnimationFrame` и защита от повторной обработки собственных обёрток.
3. Зависимость «Инструмент → Партия в оркестре» переведена на версию `v4`: варианты сначала берутся из встроенной сервером карты, затем обновляются через API. Обновляется обычный select и Jazzmin Select2, поддерживаются native/Select2 события и динамические formset-строки.
4. Преподаватель видит произведения, связанные с ним напрямую как с ответственным преподавателем, а также связанные через групповой или индивидуальный предмет. Чужие связанные произведения доступны только для просмотра.
5. Ответственный преподаватель видит всех учеников, явно назначенных в группу произведений, даже если дополнительная связь `GroupSubject`/`StudentSubject` отсутствует.
6. В карточках ученика и преподавателя выводится история зачислений/участия по всем учебным годам. Одна запись `Student` или `Teacher` повторно используется через годовые модели `StudentEnrollment` и `TeacherEnrollment`.
