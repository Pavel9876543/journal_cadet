# Отчёт по исправлению связанных данных и личного кабинета

Дата: 1 августа 2026 года.

## Реализовано

### 1. Связанные группы в карточке предмета

- Исправлен общий шаблон формы Django Admin: inline-вкладки снова фактически выводятся на страницу.
- Во вкладке «Группы, где есть этот предмет» отображаются существующие связи `GroupSubject` с настоящими данными из таблицы учебных групп.
- В строке связи можно выбрать группу и преподавателя, изменить связь или удалить только привязку предмета к группе.
- Рядом с полем группы доступны стандартные действия Django Admin: создать, просмотреть, изменить и удалить саму учебную группу в отдельном окне.
- Создание новой строки во вкладке добавляет группу к текущему предмету без повторного выбора предмета.

### 2. Универсальное управление обратными связями

Для всех зарегистрированных таблиц приложения добавлен общий блок «Связанные данные»:

- показывает обратные связи, которые не представлены отдельной inline-вкладкой;
- позволяет создать связанную запись с автоматически заполненной исходной связью;
- открывает таблицу, уже отфильтрованную по текущей записи;
- позволяет просмотреть, изменить или удалить каждую связанную запись с учётом прав пользователя;
- не дублирует связи, уже представленные отдельными вкладками;
- выводит не более 100 строк в карточке и переносит полный просмотр в отфильтрованную таблицу;
- в обычном случае использует один запрос на обратную связь; дополнительный `COUNT` выполняется только при превышении лимита.

Прямые внешние ключи продолжают использовать стандартные кнопки Django Admin рядом с полем. Таким образом, управление доступно с обеих сторон связи.

### 3. Сброс пароля через админ-панель

После успешного сохранения нового пароля удаляются все строки `TemporaryCredential`, связанные с пользователем или его логином. При ошибке формы пароль не меняется и временные данные не удаляются.

### 4. Видимость разделов личного кабинета

- Если в выбранном учебном году пользователю не назначен ни один предмет, скрываются фильтр предметов, карточка «Предметы» и форма быстрого добавления оценки.
- Если преподавателю не назначено ни одного произведения / элемента, скрывается раздел «Сдача произведений».
- Если произведение назначено, раздел отображается как раньше.
- У ученика блок произведений остаётся скрытым при отсутствии назначенных групп произведений.

### 5. Инструкция администратора

Инструкция дополнена правилами работы со связями с обеих сторон и пояснением разницы между удалением строки связи и удалением самой связанной записи.

## Проверки

Успешно выполнены:

- синтаксический разбор 82 Python-файлов;
- `compileall` для `journal`, `config` и `scripts`;
- проверка баланса основных Django template-блоков;
- `bash -n` для shell-скриптов;
- `node --check` для JavaScript-файлов;
- `git diff --check`;
- проверка целостности Git перед упаковкой.

Добавлены тесты для:

- фактического отображения вкладки «Группы, где есть этот предмет» и существующей связи;
- кнопок создания, просмотра, изменения и удаления самой группы;
- универсального блока обратных связей;
- удаления временных учётных данных после успешного сброса пароля;
- сохранения временных данных при невалидной форме сброса;
- скрытия предметов и произведений при отсутствии назначений;
- появления сдачи произведений при наличии назначенного произведения.

Профильный Django-набор подготовлен в `scripts/test-profile.sh`. В текущем рабочем окружении Django и Docker отсутствуют, а сетевой доступ к PyPI недоступен, поэтому runtime-тесты здесь не выполнились. В GitHub Actions новые тесты входят в обязательный быстрый набор `scripts/test-fast.sh`; при их ошибке CI завершится неуспешно и production CD не запустится.

Изменения моделей отсутствуют, поэтому новая миграция БД не требуется.
