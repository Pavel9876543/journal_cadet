# Проверка истории Git

Архив пересобран с активной веткой `main`.

Проверочные команды:

```bash
git status
git branch --show-current
git log --oneline -10
```

Ожидаемое состояние:

- текущая ветка — `main`;
- рабочее дерево чистое;
- последние функциональные изменения находятся в отдельных коммитах;
- финальный документационный коммит содержит `[skip ci]`.
